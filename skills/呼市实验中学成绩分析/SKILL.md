# 呼市实验中学成绩分析（班级指标与教师绩效算分）

技能支持**两种互斥的分析口径**，由数据本身有多少场成绩决定：

| 模式 | 触发条件 | 指标项数 | 指标 |
| --- | --- | --- | --- |
| **首次考试（单场成绩）** | 只有一次考试成绩（如七年级上半学期第一次期中考试），成绩表只有 `1` 结尾的科目列 | **4 项** | 均分、优秀率、合格率、参考率 |
| **两场考试对比** | 有两次考试成绩，成绩表同时有 `1` 和 `2` 结尾的科目列 | **6 项** | 排名正负、T分差、均分、优秀人数差、出库人数差、参考率 |

**判定规则**：成绩表中存在以 `2` 结尾的科目列 → 两场对比模式；否则 → 首次考试模式。用户也可以显式用 `--exam-count 1/2` 指定（显式指定优先于自动识别）。

## 输入要求

输入为单个 Excel 文件（.xlsx/.xls），包含两个工作表：

1. **成绩表**：必须含 `考号`、`姓名`、`集团班级` 三列。
   - **两场对比模式**：科目列以 `1`/`2` 结尾区分两场考试（如 `语文1`/`语文2`），`总分1`/`总分2` 可选，缺失时脚本自动按科目求和计算。第二场成绩为空视为缺考。
   - **首次考试模式**：科目列只有 `1` 结尾（如 `语文1`/`数学1`/`总分1`）；也兼容不带后缀的科目列（`语文`/`数学`/`总分`）。缺失总分时自动按科目求和计算。
2. **教师任课表**：必须含 `教师姓名`、`科目`、`班级`、`身份证号`，`校区` 可选；科目取值为学科名（与成绩表科目一致）或 `班主任`。

输入不符时先向用户说明缺失内容，不要自行猜测列名。

## 数据口径注意（脏数据判定）

- **非语数外科目可用总分代替**：除语文、数学、英语外，物理、化学、生物、政治、历史、地理等科目的成绩列可能出现「以该科目合计总分记录」的情况（即列名仍如 `物理1`/`物理2`，但数值是科目总分而非细分项得分）。**这属于正常数据口径，不是脏数据，也不要当作格式错误去报错或要求用户修改。** 只有列名缺失、考号/姓名/班级为空、或第二场成绩明显错乱（如非数值且非空白）才视为脏数据。
- **总分列**（总分1/总分2/总分）用于整体指标与班主任得分，若成绩表原生提供则优先使用，缺失时按各科求和，二者皆为合法情形。
- **首次考试模式下没有第二场**，所有「差值类」指标（排名正负、T分差、优秀人数差、出库人数差）不适用，改用均分、优秀率、合格率、参考率四项衡量（排名并入均分，不单列）。

## 执行步骤

1. **确认数据文件；没有则先出模板**。询问用户是否已有符合上述格式的 Excel。
   - 用户没有现成文件时，先运行脚本 `--template` 参数生成空白模板并交付给用户，说明填写规则（两场对比：科目列以 1/2 结尾、第二场留空表示缺考；首次考试：只填 `1` 结尾的科目列；任课表科目可填学科名或「班主任」），等用户填好后再继续；
   - 生成模板命令：`python {skill_dir}/scripts/score_analysis.py --template 模板.xlsx`（`{skill_dir}` 为本技能目录）；**首次考试模板加 `--exam-count 1`**（只生成第一场科目列）：
     ```bash
     python {skill_dir}/scripts/score_analysis.py --template 首次考试模板.xlsx --exam-count 1
     ```
2. **判定考试口径（单次 vs 两场）**。先运行检测命令拿到事实依据：

   ```bash
   python {skill_dir}/scripts/score_analysis.py --detect "<输入文件完整路径>"
   ```

   输出 JSON，含 `exam_count`（1=首次考试，2=两场对比）、`mode`、`first_subject_columns`、`second_subject_columns`、`has_total_column`。
   - `exam_count=1` → 走**首次考试口径**（四项指标）；
   - `exam_count=2` → 走**两场对比口径**（六项指标）；
   - 检测结果与用户描述不一致时（如用户说是「第一次期中考试」但文件里有 2 列），**先向用户确认以哪个口径为准**，不要自行猜测。
3. **检查文件名是否为标准格式，决定考试元信息来源**。运行：

   ```bash
   python {skill_dir}/scripts/score_analysis.py --parse-filename "<输入文件完整路径>"
   ```

   - 标准文件名格式为 `YYYY-MM-DD[_届别[_学期[_考试名称]]].xlsx`，例如 `2026-01-15_2028_1_期末考试.xlsx` 或 `2026-01-15.xlsx`。脚本会返回 JSON 解析结果（含 `exam_date`/`cohort`/`semester`/`exam_name`）或 `non-standard`。
   - **返回标准解析结果**：将这些字段作为第 4 步考试元信息的默认值（仍须用户确认或补正）。
   - **返回 `non-standard`**（文件名不以日期开头，如 `成绩数据.xlsx`）：**必须主动向用户询问考试名称**（连同缺失的日期/届别/学期一并询问，可用选择卡），不可留空直接执行。注意考试名称用于结果表与查询页面标识，缺失会导致页面显示「(未命名考试)」。
4. **与用户确定参数（每次执行前必须确认，不可跳过）**。以选择卡或清单形式向用户确认下列变量，并给出推荐默认值。**两组变量随口径不同，必须确认当前口径对应的那一组：**

   **两场对比口径（六项指标）**

   - 第一组（2 个）：**优秀比例**（全年级排名前 X% 作为优秀线，推荐 20）、**出库比例**（全年级排名前 X% 作为出库线，推荐 75）；
   - 第二组（6 个）：**排名正负、T分差、均分、优秀人数、出库人数、参考率** 的权重占比，推荐默认值依次为 **20 / 20 / 20 / 15 / 15 / 10**。

   **首次考试口径（四项指标）**

   - 第一组（2 个）：**优秀比例**（全年级排名前 X% 作为优秀线，推荐 20）、**合格比例**（全年级排名前 X% 作为合格线，推荐 80）；
   - 第二组（4 个）：**均分、优秀率、合格率、参考率** 的权重占比，推荐默认值依次为 **60 / 15 / 15 / 10**。
     - 说明：「均分与排名」视为**同一项指标**——排名本就是班级均分在同学科中的横向位次，不再单列计分，均分项合并了原「均分 25 + 排名 15」的权重，合计 60；
     - 权重可设为负数，表示该指标「越低越好」（脚本对负权重自动反向归一）；参考率权重为负时即变为「低参考率得分更高」。
   - 所有指标均在**同一科目组内**做 min-max 归一化（班主任为独立一组），故总分是组内相对分，不同科目的总分不可直接比数值、只可比组内名次。

   - 用户确认默认值或给出具体数值后，才能运行算分脚本；用户未确认前不得使用默认值直接执行。
5. **运行脚本**（按用户确认的参数与口径）。

   两场对比：

   ```bash
   python {skill_dir}/scripts/score_analysis.py -i 输入.xlsx -o 输出.xlsx \
     --exam-count 2 \
     --excellent-ratio 20 --qualified-ratio 75 \
     --rank-weight 20 --t-diff-weight 20 --avg-weight 20 \
     --excellent-weight 15 --qualified-weight 15 --reference-weight 10 \
     --exam-date YYYY-MM-DD --cohort 2028 --semester 1 --exam-name 考试名称
   ```

   首次考试：

   ```bash
   python {skill_dir}/scripts/score_analysis.py -i 输入.xlsx -o 输出.xlsx \
     --exam-count 1 \
     --excellent-ratio 20 --qualified-ratio 80 \
     --avg-weight 60 \
     --excellent-weight 15 --qualified-weight 15 --reference-weight 10 \
     --exam-date YYYY-MM-DD --cohort 2026 --semester 1 --exam-name 第一次期中考试
   ```

   > 不传 `--exam-count` 时脚本按成绩表列名自动识别；不传权重/比例时按当前口径的默认值套用。
6. 检查脚本输出的统计摘要（科目数、班级数、教师得分记录数），确认无异常后将结果 Excel 交付给用户，并简要说明该口径下的指标含义。每次分析会自动将结果写入技能目录下的 `data/analysis.db`（SQLite），无需额外操作。
7. **（可选）启动本地查询页面**。分析落库后，运行：

   ```bash
   python {skill_dir}/scripts/score_analysis.py --serve --port 8765
   ```

   命令会在浏览器可访问的 `http://127.0.0.1:8765/` 打开查询页面，提供：考试列表勾选、按录入顺序/考试日期/考试名称排序、单场考试删除（级联清理其班级指标与教师得分）、班级维度对比、校区维度对比、教师得分表（可排序），全部为纯前端图表、无外部依赖。页面会按考试口径自动切换指标图表与表格列：首次考试显示「均分 / 优秀率 / 合格率 / 参考率」，两场对比显示「均分 / T分差 / 排名正负 / 优秀人数差 / 出库人数差 / 参考率」；考试列表中首次考试带绿色「首次考试」标签。可用 `--db` 指定其他数据库路径，`--no-db` 可跳过落库。

## 数据持久化与本地查询页面

- **SQLite 落库**：每次成功分析后，`db_store.py` 将考试元信息（含 `exam_count` 场次标记）、各班级×学科明细指标、教师得分写入 `data/analysis.db`（`exams` / `class_metrics` / `teacher_scores` 三张表）。多场考试共存于同一库，支撑跨考试历史对比。
  - 两场对比指标列：`均分1/均分2/均分`、`T分1/T分2/T分差`、`线性排名1/线性排名2/正负`、`优秀人数1/2/差`、`出库人数1/2/差`、`总人数/参考人数/参考率`。
  - 首次考试指标列：`均分`、`优秀人数/优秀率`、`合格人数/合格率`、`总人数/参考人数/参考率`；`排名/线性排名` 仅作参考字段保留，不参与计分。
  - `teacher_scores` 两场对比存 `排名正负/T分差/均分/优秀人数/出库人数/参考率/总分`；首次考试存 `均分/优秀率/合格率/参考率/总分`。
  - 旧库首次运行时由 `init_db` 自动补列，无需手工迁移；旧记录的 `exam_count` 默认为 2（两场对比）。
- **本地页面**：`web_app.py` 用 Python 标准库 `http.server` 托管 `web/index.html` 并提供 `/api/*` JSON 接口，从 SQLite 读取数据；前端用原生 JS + CSS/SVG 绘图，不依赖任何 CDN 或第三方库，可完全离线运行。考试列表支持排序与删除：`/api/exam_delete`（POST，body `{"exam_id": N}`）调用 `db_store.delete_exam` 级联删除该考试在 `exams`/`class_metrics`/`teacher_scores` 三张表中的记录。
- **校区对比前提**：教师任课表需含「校区」列（班主任行带校区），脚本据此建立「班级→校区」映射；缺失校区时仅班级维度可用。

## 参数说明

| 参数 | 含义 | 两场对比默认值 | 首次考试默认值 |
| --- | --- | --- | --- |
| `--exam-count` | 考试场次数：1=首次考试，2=两场对比，auto=按列名自动识别 | auto | auto |
| `--excellent-ratio` | 优秀比例：全年级排名前 X% 的成绩线作为优秀标准 | 20 | 20 |
| `--qualified-ratio` | 合格/出库比例：全年级排名前 X% 的成绩线作为合格（出库）标准 | 75 | 80 |
| `--rank-weight` | 排名权重：两场=排名正负；单次考试下不适用（排名与均分为同一项指标，传了会被忽略） | 20 | — |
| `--t-diff-weight` | T分差权重（仅两场考试生效） | 20 | — |
| `--avg-weight` | 均分权重（单次考试下含「均分与排名」合并权重） | 20 | 60 |
| `--excellent-weight` | 优秀人数（两场）/ 优秀率（单次）的权重 | 15 | 15 |
| `--qualified-weight` | 出库人数（两场）/ 合格率（单次）的权重 | 15 | 15 |
| `--reference-weight` | 参考率权重 | 10 | 10 |
| `--exam-date/--cohort/--semester/--exam-name` | 考试信息，拼接后写入结果表首列，缺失可留空 | 空 | 空 |
| `--detect` | 仅检测文件的考试场次与科目列，输出 JSON 后退出 | — | — |
| `--log` | 将完整计算过程日志写入文本文件 | 不输出 | 不输出 |

权重之和不必为 100，脚本按各自占比独立加权。权重可为负数，表示该指标「越低越好」（负权重自动反向归一）。归一化范围为**同一科目组内**（班主任独立成组）。考试信息（日期/届别/学期/考试名称）仅用于结果表标注，不属于必须确认的变量，可顺带询问、缺失留空。

### 权重调整后如何让历史数据保持一致

「均分」指标与权重口径是随技能版本变化的。若技能新增指标或用户调整了权重，已落库的历史考试仍是旧口径，会导致跨考试走势与教师得分排名不可比。此时按以下步骤重算历史数据：

```bash
python -c "
import sys; sys.path.insert(0, r'{skill_dir}/scripts')
import db_store, json
print(db_store.rebuild_exam(r'{skill_dir}/data/analysis.db', <exam_id>))
"
```

`rebuild_exam` 会**按考试自身的口径**重算：两场对比重算 `class_metrics.均分`（= 均分2）与六项加权总分；首次考试跳过「均分 = 均分2」（其均分本身就是班级均分），直接用库中已有的 `均分/优秀率/合格率/参考率` 按四项权重重算总分。**不需要重新提供原始成绩 Excel**。权重默认取当前口径的默认值（两场 20/20/20/15/15/10，首次 60/15/15/10），如需其他权重可传 `weights={"均分": 30, ...}`。考试 `exam_id` 可通过查询页面的考试列表或 `db_store.list_exams(db_path)` 获取。执行前建议先备份 `data/analysis.db`。

## 算法口径（与用户核对指标定义时参考）

### 两场考试对比（六项指标）

- **均分**：对每一科，按**班级范围**计算该科均分（班级内参加两场考试学生的该科平均分），指标值**直接取第二场班级均分，不做两场之差**。
  设计意图：这是一项**结果评价**，用于平衡只看「进步幅度」带来的偏差——基础薄弱的班级大幅进步与基础扎实的班级小幅进步，进步幅度可能相同甚至前者更大，但结果水平（均分）能区分二者。因此它与排名正负/T分差（进步幅度）是互补关系，而非重复计算。
  口径说明：学科教师按各自班级的**科目**均分比较，班主任按**总分**均分比较。
- **T分差**：班级均分做 T 标准化（T = 50 + 10×(X−μ)/σ，μ/σ 取全体班级均分的均值与标准差），T分差 = 第二场 − 第一场。
- **排名正负**：班级均分线性排名 rank = 1 + (N−1)×(Xmax−x)/(Xmax−Xmin)，正负 = 第一场排名 − 第二场排名，正值表示进步。
- **优秀/出库人数差**：取全年级排名前 X% 位置的分数为阈值，统计各班两场达标人数，差值 = 第二场 − 第一场。
- **参考率**：两场都有分数的学生视为参考；班级参考率 = 参考人数/总人数。
- **教师总分**：任课教师取所教班级×科目指标，班主任取「总分」科目指标；六项指标 min-max 归一到 0~100 后按权重（20/20/20/15/15/10）加权。多班任教时，排名正负/T分差/均分/参考率取均值，优秀人数/出库人数取合计。
  **归一化按科目分组进行**（班主任视为独立一组）：每项指标的 min/max 只在同一科目组内取，因此总分体现的是「同科教师之间的相对表现」，可跨科目按组内排名横向比较。
  各科人数悬殊（如语文 40+ vs 历史/生物 20+）时，若混在一起归一，小科目的分布会被大科目主导，且某科得分会受本次运行是否凑齐其他科目影响——分组归一消除了这两个问题。
- **指标性质**：六项指标中，「排名正负 / T分差」衡量**进步幅度**，「均分」衡量**结果水平**，「优秀人数 / 出库人数」衡量**达标结构变化**，「参考率」衡量**参与度**，四类互补构成完整评价。
- **统计范围一致性**：除参考率外，其余五项指标均只统计「两场都有成绩」的参考学生，保证班内各指标口径统一。

### 首次考试（四项指标）

只有一次成绩时，「进步幅度」类指标无参照系，改用**绝对水平 + 结构占比**组合评价：

- **均分**：该班该科**有成绩学生**的平均分（缺考不计入平均）。学科教师按所教班级的科目均分，班主任按所带班级的总分均分。
  - **「均分与排名」按同一项指标处理**：班级在同学科中的名次，本质就是班级均分的横向位次，与均分同源，故不单列为独立指标、不单独计分。均分项因此合并了原「均分 25 + 排名 15」的权重，合计 60。
  - 班级均分仍在库中附带 `排名`/`线性排名` 字段（排名 = 均分降序名次，线性排名 = 1 + (N−1)×(Xmax−x)/(Xmax−Xmin)），仅作**参考字段**与各汇总表的行序，不参与任何计分。
- **优秀率**：该班**达到优秀线**的人数 ÷ 该班参考人数。优秀线 = 全年级该科按成绩降序排列、位于**前 X%** 名次处的分数（推荐 X=20）。含义即「全班有多少比例的学生进入了集团前 X%」。
- **合格率**：该班**达到合格线**的人数 ÷ 该班参考人数。合格线 = 全年级该科按成绩降序排列、位于**前 Y%** 名次处的分数（推荐 Y=80，可变）。与旧 skill 的出库比例同义，只是首次考试里改称「合格率」。
  - **分母说明**：优秀率/合格率的分母用**参考人数**（有该科成绩的学生数）而非在册人数，参考率单独成一项指标，两者互补不重复计分。
- **参考率**：班级参考人数 ÷ 在册总人数，口径与多次考试完全一致。
- **教师总分**：四项指标 min-max 归一到 0~100 后按权重（60/15/15/10）加权，**仍在同一科目组内归一**（班主任独立一组）。多班任教时四项指标一律取**均值**（比率类指标不可求和）。

## 输出内容

- **两场对比口径**：结果 Excel 含 7 个工作表——所有科目均分汇总（含 `均分1`/`均分2`/`均分`/`均分排名`）、排名正负汇总、T分差汇总、优秀人数汇总、出库人数汇总、参考率汇总、教师得分表（含按科目排名）。每张表首列为拼接的考试信息，教师相关表附教师姓名与校区。
- **首次考试口径**：结果 Excel 含 5 个工作表——**均分汇总**（含 `均分`/`均分排名`/`总人数`/`参考人数`）、**优秀率汇总**（含 `优秀人数`/`优秀率`/学科内排名）、**合格率汇总**（含 `合格人数`/`合格率`/学科内排名）、**参考率汇总**（含 `总人数`/`参考人数`/`参考率`/排名）、**教师得分表**（含 `均分`/`优秀率`/`合格率`/`参考率`/`总分`/`得分排名`）。每张表首列为拼接的考试信息，教师相关表附教师姓名与校区。
  - 各汇总表末列的「排名 / 均分排名」是**本表内部按该表指标排序的行序**，与两场对比口径各表末列一致，**不是独立评价指标**。

数据落库到 SQLite 的 `class_metrics` 与 `teacher_scores` 表；本地查询页面据此按考试口径渲染对应图表（两场 6 类班级指标图表，首次考试 4 类班级指标图表），并提供校区聚合对比与教师得分表。

## 依赖

- 成绩分析（Excel 读写与计算）：仅需 Python 3 与 `pandas`、`openpyxl`（`numpy` 随 pandas 安装）。运行前如报缺库，先 `pip install pandas openpyxl`。
- SQLite 落库与本地查询页面：仅用 Python 标准库（`sqlite3`、`http.server`），**无需额外安装**；前端图表亦无外部依赖，可离线运行。
