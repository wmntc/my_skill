# 呼市实验中学成绩分析（班级指标与教师绩效算分）

## 输入要求

输入为单个 Excel 文件（.xlsx/.xls），包含两个工作表：

1. **成绩表**：必须含 `考号`、`姓名`、`集团班级` 三列；科目列以 `1`/`2` 结尾区分两场考试（如 `语文1`/`语文2`），`总分1`/`总分2` 可选，缺失时脚本自动按科目求和计算。第二场成绩为空视为缺考。
2. **教师任课表**：必须含 `教师姓名`、`科目`、`班级`、`身份证号`，`校区` 可选；科目取值为学科名（与成绩表科目一致）或 `班主任`。

输入不符时先向用户说明缺失内容，不要自行猜测列名。

## 数据口径注意（脏数据判定）

- **非语数外科目可用总分代替**：除语文、数学、英语外，物理、化学、生物、政治、历史、地理等科目的成绩列可能出现「以该科目合计总分记录」的情况（即列名仍如 `物理1`/`物理2`，但数值是科目总分而非细分项得分）。**这属于正常数据口径，不是脏数据，也不要当作格式错误去报错或要求用户修改。** 只有列名缺失、考号/姓名/班级为空、或第二场成绩明显错乱（如非数值且非空白）才视为脏数据。
- **总分列**（总分1/总分2）用于整体指标与班主任得分，若成绩表原生提供则优先使用，缺失时按各科求和，二者皆为合法情形。

## 执行步骤

1. **确认数据文件；没有则先出模板**。询问用户是否已有符合上述格式的 Excel。
   - 用户没有现成文件时，先运行脚本 `--template` 参数生成空白模板并交付给用户，说明填写规则（科目列以 1/2 结尾、第二场留空表示缺考、任课表科目可填学科名或「班主任」），等用户填好后再继续；
   - 生成模板命令：`python {skill_dir}/scripts/score_analysis.py --template 模板.xlsx`（`{skill_dir}` 为本技能目录）。
2. **检查文件名是否为标准格式，决定考试元信息来源**。运行：

   ```bash
   python {skill_dir}/scripts/score_analysis.py --parse-filename "<输入文件完整路径>"
   ```

   - 标准文件名格式为 `YYYY-MM-DD[_届别[_学期[_考试名称]]].xlsx`，例如 `2026-01-15_2028_1_期末考试.xlsx` 或 `2026-01-15.xlsx`。脚本会返回 JSON 解析结果（含 `exam_date`/`cohort`/`semester`/`exam_name`）或 `non-standard`。
   - **返回标准解析结果**：将这些字段作为第 3 步考试元信息的默认值（仍须用户确认或补正）。
   - **返回 `non-standard`**（文件名不以日期开头，如 `成绩数据.xlsx`）：**必须主动向用户询问考试名称**（连同缺失的日期/届别/学期一并询问，可用选择卡），不可留空直接执行。注意考试名称用于结果表与查询页面标识，缺失会导致页面显示「(未命名考试)」。

3. **与用户确定两组参数（每次执行前必须确认，不可跳过）**。以选择卡或清单形式向用户确认以下两组变量，并给出推荐默认值：
   - 第一组（2 个）：**优秀比例**（全年级排名前 X% 作为优秀线）、**出库比例**（全年级排名前 X% 作为出库线）；
   - 第二组（6 个）：教师总分中六项指标的权重占比——**排名正负、T分差、均分、优秀人数、出库人数、参考率**，推荐默认值依次为 **20 / 20 / 20 / 15 / 15 / 10**。
   - 用户确认默认值或给出具体数值后，才能运行算分脚本；用户未确认前不得使用默认值直接执行。
   - 权重可设为负数，表示该指标「越低越好」（脚本对负权重自动反向归一）；参考率权重为负时即变为「低参考率得分更高」。
   - 六项指标均在**同一科目组内**做 min-max 归一化（班主任为独立一组），故总分是组内相对分，不同科目的总分不可直接比数值、只可比组内名次。
4. **运行脚本**（按用户确认的参数）：

```bash
python {skill_dir}/scripts/score_analysis.py -i 输入.xlsx -o 输出.xlsx \
  --excellent-ratio 20 --qualified-ratio 75 \
  --rank-weight 20 --t-diff-weight 20 --avg-weight 20 \
  --excellent-weight 15 --qualified-weight 15 --reference-weight 10 \
  --exam-date YYYY-MM-DD --cohort 2028 --semester 1 --exam-name 考试名称
```

5. 检查脚本输出的统计摘要（科目数、班级数、教师得分记录数），确认无异常后将结果 Excel 交付给用户，并简要说明六项指标含义。每次分析会自动将结果写入技能目录下的 `data/analysis.db`（SQLite），无需额外操作。
6. **（可选）启动本地查询页面**。分析落库后，运行：

```bash
python {skill_dir}/scripts/score_analysis.py --serve --port 8765
```

   命令会在浏览器可访问的 `http://127.0.0.1:8765/` 打开查询页面，提供：考试列表勾选、按录入顺序/考试日期/考试名称排序、单场考试删除（级联清理其班级指标与教师得分）、班级维度对比（7 个指标条形图横向 4 列展示，图表标签为 `<校区>-<教师姓名>`，教师姓名取自教师任课表，缺项自动省略、两者皆缺回退班级名；另有跨考试走势折线图，含第二场均分/均分/T分差三条）、校区维度对比（按校区聚合，含平均均分）、教师得分表（可排序），全部为纯前端图表、无外部依赖。可用 `--db` 指定其他数据库路径，`--no-db` 可跳过落库。

## 数据持久化与本地查询页面

- **SQLite 落库**：每次成功分析后，`db_store.py` 将考试元信息、各班级×学科明细指标（含 `均分1/均分2/均分` 与从教师任课表解析的 `教师姓名`，学科教师取对应任课教师、「总分」取班主任）、教师得分（含 `均分`）写入 `data/analysis.db`（`exams` / `class_metrics` / `teacher_scores` 三张表）。多场考试共存于同一库，支撑跨考试历史对比。旧库首次运行时由 `init_db` 自动补列（`class_metrics.均分`、`teacher_scores.均分`），无需手工迁移。
- **本地页面**：`web_app.py` 用 Python 标准库 `http.server` 托管 `web/index.html` 并提供 `/api/*` JSON 接口，从 SQLite 读取数据；前端用原生 JS + CSS/SVG 绘图，不依赖任何 CDN 或第三方库，可完全离线运行。考试列表支持排序与删除：`/api/exam_delete`（POST，body `{"exam_id": N}`）调用 `db_store.delete_exam` 级联删除该考试在 `exams`/`class_metrics`/`teacher_scores` 三张表中的记录。
- **校区对比前提**：教师任课表需含「校区」列（班主任行带校区），脚本据此建立「班级→校区」映射；缺失校区时仅班级维度可用。

## 参数说明

| 参数 | 含义 | 推荐默认值（须用户确认） |
| --- | --- | --- |
| `--excellent-ratio` | 优秀比例：全年级排名前 X% 的成绩线作为优秀标准 | 20 |
| `--qualified-ratio` | 出库比例：全年级排名前 X% 的成绩线作为出库标准 | 75 |
| `--rank-weight` 等 6 项 | 教师总分中排名正负/T分差/均分/优秀人数/出库人数/参考率的权重占比 | 20 / 20 / 20 / 15 / 15 / 10 |
| `--exam-date/--cohort/--semester/--exam-name` | 考试信息，拼接后写入结果表首列，缺失可留空 | 空 |
| `--log` | 将完整计算过程日志写入文本文件 | 不输出 |

六项权重之和不必为 100，脚本按各自占比独立加权。权重可为负数，表示该指标「越低越好」（负权重自动反向归一）。归一化范围为**同一科目组内**（班主任独立成组）。考试信息（日期/届别/学期/考试名称）仅用于结果表标注，不属于必须确认的变量，可顺带询问、缺失留空。

### 权重调整后如何让历史数据保持一致

「均分」指标与权重口径是随技能版本变化的。若技能新增指标或用户调整了权重，已落库的历史考试仍是旧口径，会导致跨考试走势与教师得分排名不可比。此时按以下步骤重算历史数据：

```bash
python -c "
import sys; sys.path.insert(0, r'{skill_dir}/scripts')
import db_store, json
print(db_store.rebuild_exam(r'{skill_dir}/data/analysis.db', <exam_id>))
"
```

`rebuild_exam` 仅依赖库中已有的 `均分2` 与六项指标列，**不需要重新提供原始成绩 Excel**，会重算 `class_metrics.均分`（= 均分2）、`teacher_scores.均分` 与 `teacher_scores.总分`。权重默认取当前技能默认值（20/20/20/15/15/10），如需其他权重可传 `weights={"均分": 30, ...}`。考试 `exam_id` 可通过查询页面的考试列表或 `db_store.list_exams(db_path)` 获取。执行前建议先备份 `data/analysis.db`。

## 算法口径（与用户核对指标定义时参考）

- **均分**：对每一科，按**班级范围**计算该科均分（班级内参加两场考试学生的该科平均分），
  指标值**直接取第二场班级均分，不做两场之差**。
  设计意图：这是一项**结果评价**，用于平衡只看「进步幅度」带来的偏差——基础薄弱的班级大幅进步
  与基础扎实的班级小幅进步，进步幅度可能相同甚至前者更大，但结果水平（均分）能区分二者。
  因此它与排名正负/T分差（进步幅度）是互补关系，而非重复计算。
  口径说明：学科教师按各自班级的**科目**均分比较，班主任按**总分**均分比较。
- **T分差**：班级均分做 T 标准化（T = 50 + 10×(X−μ)/σ，μ/σ 取全体班级均分的均值与标准差），T分差 = 第二场 − 第一场。
- **排名正负**：班级均分线性排名 rank = 1 + (N−1)×(Xmax−x)/(Xmax−Xmin)，正负 = 第一场排名 − 第二场排名，正值表示进步。
- **优秀/出库人数差**：取全年级排名前 X% 位置的分数为阈值，统计各班两场达标人数，差值 = 第二场 − 第一场。
- **参考率**：两场都有分数的学生视为参考；班级参考率 = 参考人数/总人数。
- **教师总分**：任课教师取所教班级×科目指标，班主任取「总分」科目指标；六项指标 min-max 归一到 0~100 后按权重（20/20/20/15/15/10）加权。多班任教时，排名正负/T分差/均分/参考率取均值，优秀人数/出库人数取合计。
  **归一化按科目分组进行**（班主任视为独立一组）：每项指标的 min/max 只在同一科目组内取，
  因此总分体现的是「同科教师之间的相对表现」，可跨科目按组内排名横向比较。
  各科人数悬殊（如语文 40+ vs 历史/生物 20+）时，若混在一起归一，小科目的分布会被大科目主导，
  且某科得分会受本次运行是否凑齐其他科目影响——分组归一消除了这两个问题。
- **指标性质**：六项指标中，「排名正负 / T分差」衡量**进步幅度**，「均分」衡量**结果水平**，
  「优秀人数 / 出库人数」衡量**达标结构变化**，「参考率」衡量**参与度**，四类互补构成完整评价。
- **统计范围一致性**：除参考率外，其余五项指标均只统计「两场都有成绩」的参考学生，保证班内各指标口径统一。

## 输出内容

结果 Excel 含 7 个工作表：所有科目均分汇总（含 `均分1`/`均分2`/`均分`/`均分排名`）、排名正负汇总、T分差汇总、优秀人数汇总、出库人数汇总、参考率汇总、教师得分表（含按科目排名）。每张表首列为拼接的考试信息，教师相关表附教师姓名与校区。

数据落库到 SQLite 的 `class_metrics`（含 `均分1/均分2/均分`）与 `teacher_scores`（含 `均分`）表；本地查询页面据此提供 7 类班级指标图表（均分、第二场均分、T分差、排名正负、优秀人数差、出库人数差、参考率）、校区聚合对比与教师得分表。

## 依赖

- 成绩分析（Excel 读写与计算）：仅需 Python 3 与 `pandas`、`openpyxl`（`numpy` 随 pandas 安装）。运行前如报缺库，先 `pip install pandas openpyxl`。
- SQLite 落库与本地查询页面：仅用 Python 标准库（`sqlite3`、`http.server`），**无需额外安装**；前端图表亦无外部依赖，可离线运行。
